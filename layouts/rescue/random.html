救助依頼ランダム生成

「ポケモン不思議のダンジョン 時の探検隊・闇の探検隊・空の探検隊」の救助依頼をランダムに作成するツール。
元々は救助TA(タイムアタック)の練習ツールとして自分用に使っていたもの。難しい救助の挑戦、検証、TA企画等にどうぞ。

  • 異なるリージョンの依頼は受けることができるが、チーム名は固定される。
    日本版の場合「ポケモンズ」になる。
  • バージョンを「空」にしている場合、「空 (1)」「空 (2)」のいずれかで生成される。内部の値が異なるだけでこれといった違いは無い。
  • フロアを0Fにした場合、救助地点が無くなる代わりにダンジョンをクリアすることで救助完了になる。
  • 固定フロアの救助依頼は受けられない。
  • テストダンジョンは {{ with site.GetPage "/wondermail/anydungeon" }} 強制解禁 {{ else }} 強制解禁 {{ end }} して一度クリアしていないと受けられないので注意。
  • 海外版(北米/欧州)の6～10文字チーム名には未対応。海外版に対応したチーム名を入力しても実際に表示される文字は異なるものになるので注意。
  • このツールで生成したパスワードは「捏造パス」なので利用は自己責任で。
