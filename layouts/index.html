捏造パス関連
{{ with ref . "/wondermail/wondermail.html" }} ふしぎなメール生成機 {{ end }}

あらゆる組み合わせのふしぎなメール(捏造パス)を作ります。
レア道具が貰える依頼を作ったり、難しい依頼を作ったり。

{{ with ref . "/wondermail/anydungeon.html" }} ダンジョン強制解禁 {{ end }}

任意のダンジョンを捏造パスで強制解禁します。
通常では行けないダンジョンも解禁できます。バグ技につき取扱注意。
※空の探検隊限定

{{ with ref . "/wondermail/anyegg.html" }} 任意タマゴ孵化 {{ end }}

任意のポケモンを捏造パスで入手します。
通常のポケモン、進化後、伝説、未使用ポケモンまでほぼすべて入手可能。

{{ with ref . "/rescue/duplicate.html" }} 救助依頼複製 {{ end }}

救助依頼の複製をするツール。役に立つ救助保存の複製にどうぞ。

{{ with ref . "/rescue/self-rescue.html" }} 自演救助 {{ end }}

倒されてしまった時の救助を自演で行います。ついでに道具も貰えます。

{{ with ref . "/rescue/random.md" }} 救助依頼ランダム生成 {{ end }}

たすけてメールをランダムに生成します。
タイムアタックだったり、難しい救助に挑戦したり。
